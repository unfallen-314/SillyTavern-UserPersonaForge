# User Persona Forge（UPF）

跨世界观的 User 人设生成器。**写好一份核心性格，AI 读完角色卡的世界书后，自动给你生成一个贴合该世界观的身份，一键写回世界书。**

不用再为每个世界观手写一遍人设。

## 安装

### 方式 A：通过 Git URL 安装（推荐）

酒馆 → 顶部「积木块」图标 → **管理扩展程序** → **安装扩展程序** → 输入 Git URL：

```
https://github.com/unfallen-314/SillyTavern-UserPersonaForge
```

分支或标签名留空（或填 `main`），选「只给我安装」或「给所有人安装」，点确认。装完**刷新浏览器**，回「管理扩展程序」确认已启用。

**更新**：同一界面点「更新」即可（manifest 已启用 `auto_update`，酒馆启动时也会自动检查）。

### 方式 B：手动安装

把文件夹拷到 `<SillyTavern安装目录>/public/scripts/extensions/third-party/`（或单用户模式 `data/<用户名>/extensions/`），刷新浏览器。

## 三步上手

### ① 写核心性格（只写一次）

扩展设置 → *User Persona Forge* → 展开 → 第一个框：

```
user 是个……的人
性格：
爱好：
说话方式：
底线 / 雷区：
对关系的态度：
```

**铁律：不要写世界观专属名词。** 写「沉迷拆解复杂系统」，别写「我是程序员」——前者在西幻、赛博、校园都能被翻译成等价物。

### ② 点「生成身份」

选中一张角色卡，然后：

- **要求框**：想当什么身份就写什么，比如「和主角敌对的赏金猎人」「他从小一起长大的邻居」。**留空 = 让 AI 自由发挥**。
- **条目名**：默认是 `玩家人物设定`，可改。
- **素材过滤**（生成结果框下方）：列出这本世界书的所有条目，**勾掉的不会被 AI 读到**。想挡掉剧透条目、或者跟玩家身份无关的条目就用它。带搜索框，条目多也不怕。
- 点**生成身份**。

插件会自动把这三样一起发给**你当前配置的模型**：

1. 你的核心性格（不可改变）
2. **当前角色卡的世界书内容** + 角色卡的设定/性格/场景/作者备注
3. 你的额外要求

生成结果直接出现在下面的框里，**可以随便改**，不满意就点「再生成一次」。

### ③ 注入到世界书

点**「注入 / 更新到世界书」**。插件会在该角色卡的世界书里创建一条：

| 属性 | 值 | 说明 |
|---|---|---|
| 条目名 | `玩家人物设定`（可改） | 在世界书列表里显示的名字 |
| 常驻 | 是 | 蓝色条目，每次生成都会被读到 |
| 插入位置 | 角色定义之前 | 保证模型优先看到你是谁 |
| 启用 | 是 | 可随时关掉 |

注入后状态行会显示「已注入『玩家人物设定』· 启用中」，旁边三个按钮：

- **启用 / 禁用** —— 关掉就不进 prompt 了，随时能开回来
- **注入 / 更新** —— 改完内容再点一次，覆盖同一条（不会重复创建）
- **从世界书移除** —— 删掉这条

> 如果该角色卡**没有绑定世界书**，插件会自动创建一本 `UPF-<角色名>` 并绑定到这张卡，不用你手动建。

### ④ 生成 NPC（可选）

面板里的「④ 生成 NPC」：写想生成什么样的 NPC（留空则 AI 自由发挥），点**生成 NPC**，改满意后点**注入为绿灯条目**。

**NPC 写成绿灯条目** —— 非常驻，只有在对话里提到关键词时才注入，不常驻、不占上下文。

所以 AI 生成时会连「触发关键词」一起给出来（NPC 的名字、称号、别人可能怎么称呼他），并且自动填进关键词框——**你可以改**。

- 关键词框留空 → 用 AI 生成的
- 关键词框填了 → 以你填的为准
- **没关键词会拒绝注入**（绿灯条目没有关键词等于永远不触发，白占一条）

**为什么 NPC 用绿灯而不是常驻**：user 身份必须每次都读到（所以常驻），但 NPC 如果也常驻，加三四个就把上下文吃满了。绿灯只在需要的时候出现。

## 斜杠命令

| 命令 | 作用 |
|---|---|
| `/upf` | 查看当前角色、世界书、注入状态 |
| `/upf gen 要求` | 生成身份（要求留空 = 随机），结果直接输出到聊天 |
| `/upf inject` | 把刚生成的注入世界书 |
| `/upf on` / `/upf off` | 启用 / 禁用注入的条目 |
| `/upf list` | 列出身份档案库 |

## 关于读取的世界书素材

插件会按顺序收集（受面板里的字符上限约束，默认 6000 字）：

1. 角色卡自身：名字 / 描述 / 性格 / 场景 / 作者备注
2. **角色卡绑定的世界书**（常驻条目优先）—— 世界观骨架通常在常驻条目里
3. 角色卡内嵌的世界书（V2 `character_book`）

**排除条目**：面板的「素材过滤」里会列出这些条目，勾选=排除。排除记录按世界书分别保存，换卡互不影响，随时可以「清空排除」。列表里常驻条目排最前（一般就是世界观骨架），被排除的在同组内靠前方便复查。

## 注意事项

- 需要 **SillyTavern 1.13+**。
- 生成走的是你在酒馆里配置的模型/API，不额外花别的钱。
- 本扩展只写入「你指定名字的那一条世界书条目」，不会动你世界书里的其他条目，也不改角色卡本体（除了在没世界书时自动建一本并绑定）。
- 身份档案库（面板下半部分）是给**宏注入**用的备选方案，用世界书注入的话可以完全忽略它。

## 附：宏注入（备选用法）

如果你不想往世界书里塞东西，也可以用宏。注册了三个：

| 宏 | 作用 |
|---|---|
| `{{user_persona}}` | 内核 + 身份合并（别名 `{{me}}`） |
| `{{user_core}}` | 只要核心性格 |
| `{{user_identity}}` | 只要身份层 |

在人设描述框填 `{{user_persona}}`（面板有按钮一键写入），之后在档案库里维护身份、绑定到角色卡即可。切卡自动切换。

## 数据在哪

全部在扩展设置里（`settings.json` 的 `user_persona_forge` 段）。面板可导出 / 导入 JSON 备份。
